Независимый проект переводов интерфейса [Paperclip](https://github.com/paperclipai/paperclip). Английский каталог содержит исходные строки, русский — их первый перевод. Репозиторий содержит каталоги, проверки и патч для конкретной ревизии Paperclip; это не официальный релиз Paperclip.

## Выбрать канал

| Канал локализации | Совместимая версия Paperclip | Когда выбирать |
| --- | --- | --- |
| [Stable — v2026.9.13.1](https://github.com/DrMaks22/paperclip-localizations/releases/tag/v2026.9.13.1) | Официальный стабильный выпуск **v2026.831.1**, коммит `65ec059` | Основной вариант для этой стабильной версии. Английский и русский интерфейс. |
| [Beta — v2026.9.13.1-beta.1](https://github.com/DrMaks22/paperclip-localizations/releases/tag/v2026.9.13.1-beta.1) | Проверенный снимок **master**, коммит `04e3642` | Для отдельной тестовой сборки на указанном коммите master и проверки новых языковых каталогов. |

**Stable и beta — разные патчи для разных исходников.** Beta не подходит к стабильному выпуску и не обновляется автоматически вместе с master. `Latest` в GitHub Releases относится только к stable. Номер релиза локализации не совпадает с номером Paperclip.

В ветке `main` ведётся разработка beta. Для установки скачивайте выбранный **релиз**, а не текущую ветку. Полные коммиты, различия и результаты проверок приведены в [описании каналов](docs/RELEASES.md); сведения о каналах в формате JSON доступны в [`channels.json`](channels.json).

## Установить с помощью агента

Скопируйте задание в **Codex, Claude Code или OpenCode**. Замените путь на свой; остальные условия установки описаны в документации указанного релиза.

```text
Установи локализацию Paperclip из DrMaks22/paperclip-localizations,
стабильный релиз v2026.9.13.1 для Paperclip v2026.831.1.
Мой исходный Git-репозиторий Paperclip находится в
/absolute/path/to/paperclip. Прочитай и выполни инструкции этого релиза:
https://github.com/DrMaks22/paperclip-localizations/blob/v2026.9.13.1/docs/AGENT-INSTALL.md
Сначала проверь исходники, manifest.json, контрольные суммы и совместимость.
Подготовь отдельный worktree на manifest.baseCommit, проверь и примени патч,
выполни необходимые проверки сборки и сообщи результат.
Развёртывание действующего экземпляра требует отдельного указания.
```

Это обычное задание для агента, а не специальная команда продукта. Для beta используйте [отдельное задание](docs/RELEASES.md#установка-beta-с-агентом). Агент не должен самостоятельно менять выбранный канал или понижать версию работающего экземпляра. [Инструкция для агента](docs/AGENT-INSTALL.md) также описывает, как работать с уже установленным Paperclip.

## Установить вручную

Понадобятся **Node.js 24**, Git и исходный репозиторий Paperclip. Скачайте закреплённый релиз локализации в отдельный каталог, затем выполните [инструкцию по установке](docs/INSTALL.ru.md). Основные команды из каталога локализации:

```bash
node apply.mjs --repo /absolute/path/to/paperclip-localized --check
node apply.mjs --repo /absolute/path/to/paperclip-localized --apply
```

Целевой worktree должен быть чистым и точно соответствовать `baseCommit` из [`manifest.json`](manifest.json). Установщик работает без сети: он проверяет и изменяет исходники. Установку зависимостей, работу с базой данных, запуск и развёртывание выполняйте в привычном порядке.

Попытка повторно применить патч или выполнить `--check` после его применения завершится отказом. Для проверки установленного патча используйте `--reverse --check`; для снятия — `--reverse --apply`. Подробности и порядок обновления — в [инструкции](docs/INSTALL.ru.md#обновление-и-снятие-патча).

## Совместимость и границы перевода

[`manifest.json`](manifest.json) — источник сведений о поддерживаемой ревизии. Совместимость с другими или будущими версиями Paperclip не гарантируется. Для обновления работающего экземпляра сначала подготовьте резервную копию и отдельную сборку. Не понижайте его версию ради применения патча.

Перевод охватывает включённые в релиз каталоги и проверенные изменения интерфейса. Наличие перевода в каталоге само по себе не доказывает, что любой динамический экран полностью переведён. Пользовательский контент, ответы агентов, журналы и исходные диагностические сообщения провайдеров могут оставаться на языке источника.

Если Paperclip установлен глобально через npm или запущен из готового Docker-образа, этот патч нельзя просто применить к установленному пакету или контейнеру. Нужна совместимая сборка из исходников; [варианты установки](docs/INSTALL.ru.md#уже-работающий-paperclip) описаны отдельно.

## Добавить язык или исправить перевод

Исправления и новые языки принимаются через пул-реквесты в `main`. Для нового языка создайте файл `locales/<BCP47>.json`, например `locales/de.json`, на основе [`locales/en.json`](locales/en.json) и добавьте перевод, сохранив вложенную структуру. В beta название языка на его собственном языке определяется средствами проекта; вручную менять переключатель языка не нужно. Текущий stable сохраняет ранее проверенную интеграцию EN/RU; перенос новых языков в stable требует отдельного проверенного выпуска.

Перед слиянием проверьте ключи, подстановки, формы множественного числа и разметку. Отдельно проверьте естественность перевода и его точность по отношению к английскому тексту, а также просмотрите основные экраны. Для языков с письмом справа налево требуется отдельная визуальная проверка. Полный порядок — в [CONTRIBUTING.md](CONTRIBUTING.md).

```bash
npm test
npm run validate
```

Для сообщения об ошибке используйте [шаблон проблемы с переводом](https://github.com/DrMaks22/paperclip-localizations/issues/new?template=translation.yml) или [шаблон проблемы с установкой](https://github.com/DrMaks22/paperclip-localizations/issues/new?template=installation.yml).

## Обновления и происхождение

По понедельникам GitHub проверяет отдельно новый стабильный выпуск Paperclip и изменения master, а агент Codex готовит необходимые обновления перевода и патча в отдельных ветках для соответствующих каналов. Еженедельное задание Codex настроено на 10:00 по Москве. Слияние, публикация любого релиза и развёртывание требуют отдельного одобрения сопровождающего. Расписание, ограничения автоматизации и проверки перед выпуском описаны в [регламенте сопровождения](docs/MAINTENANCE.md).

Проект развивает работу, представленную в [upstream PR #11125](https://github.com/paperclipai/paperclip/pull/11125). Над ней работал Evyatar Bluzer ([@bluzername](https://github.com/bluzername)); пул-реквест первоначально отправил [@convergentaru](https://github.com/convergentaru). Дальнейшие изменения предложены для upstream в [пул-реквесте #12989](https://github.com/paperclipai/paperclip/pull/12989); пользоваться этим независимым репозиторием можно независимо от того, примут ли пул-реквест. Сопровождение — [@DrMaks22](https://github.com/DrMaks22). Вклад исходных авторов и записи `Co-authored-by` сохраняются; проверка агентом не обозначается как проверка человеком.

Лицензия — [MIT](LICENSE); атрибуция Paperclip и авторов исходной локализации сохраняется.
