## Limits and release policy

- This snapshot uses an unchanged official lockfile. Isolated UI dependency preparation uses Node 24, pnpm 9.15.4, frozen resolution and disabled lifecycle scripts; no dependency repair is shipped. This differs from historical stable's known upstream lockfile mismatch.
- Full-monorepo/native-runner tests, Storybook visual regression, live-provider/backend E2E, production deployment and exhaustive human/visual review are not claimed. Browser checks use synthetic loopback fixtures, not real credentials, a real server/database or a live external service.
- Generic linguistic/length heuristics require classification; they are not reported as a raw zero-warning pass. Long safety instructions are not shortened by removing conditions.
- Upstream PR #12989 remains a separate, unmerged proposal with conflicts at unchanged head `cfe87f3`. Its previous failed upstream E2E result is not made green by this distribution's checks. Its branch is not updated by this heartbeat.
- No tag, release, immutable asset or running instance is changed. A future approved beta release must be a prerelease and never `Latest`. Stable's independent file-drag correction is proposed in PR #10, not merged into this payload.
