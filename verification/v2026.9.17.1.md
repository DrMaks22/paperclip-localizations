# Verification — stable v2026.9.17.1

## Identity and scope

This independent community localization targets official Paperclip [v2026.916.0](https://github.com/paperclipai/paperclip/releases/tag/v2026.916.0), exact commit `dffc2b3ca1b9e88fa21cb17493083e682dffd1ca`. It does not target an arbitrary newer master or a prebuilt npm/container installation.

- Reviewed integration identifier: `364e448fa6bbd19c6012c42feaa55c306179be7c`.
- Resulting Git tree: `dae14e85dabf726716edf6a0aac94dd31dca368c`.
- Foundation and installable patch SHA-256: `12b685301d5cd8b6bf878bb2597dc39a6221ee23661f7dda5122851e72ba4acf`.
- Scope: 829 paths — 826 UI paths and the three approved locale support scripts. The net patch does not change server, CLI, database, API schemas, package manifests or lockfiles.
- Catalogs: 16,646 English and 16,978 Russian messages, including language-specific plural forms. The extra Russian forms are not a coverage percentage.
- Relative to published stable `v2026.9.13.1`: English adds 1,399 entries, edits one and removes 416; Russian adds 1,415 entries, edits one and removes 416. These are catalog-entry changes, not counts of newly translated screens.

The previous stable release remains immutable and applies only to Paperclip `v2026.831.1`. Beta `v2026.9.13.1-beta.1` and its payload are unchanged. The new stable uses `pinned-en-ru`: it exports the reviewed current EN/RU integration without applying beta's community runtime overlays. Additional languages require a separately reviewed release; simply adding another JSON does not enable it in this stable runtime.

The integration retains the original localization ancestry and attribution documented in [NOTICE](../NOTICE.md). Its local integration identifier is not required to install or reproduce the patch: the public pinned upstream source, complete foundation, catalogs and source lock are sufficient.

These are classified exclusions, not a claim that a heuristic proves every reachable screen is translated. Dynamic values were examined separately. Exact code/message matching and source provenance gate finite first-party diagnostics; unknown provider messages and raw copied notice bodies remain unchanged.

## Explicit limits

- Root `pnpm build` and `pnpm typecheck` were attempted but stopped in the unchanged Rust runner because this Mac requires acceptance of the Xcode/Apple SDK licence. No licence was accepted or SDK configuration changed. The separate UI typecheck and production build passed. Do not describe the full monorepo build/typecheck as green.
- Full server, Rust runner, live-provider and deployment end-to-end suites were not completed for this UI patch. Browser review is a selected-surface check, not exhaustive coverage of every possible state or a production rollout.
- User content, agent responses, prompts, logs, unknown provider diagnostics, CLI text, third-party plugins and publisher-controlled announcement content retain their source language. Changing the interface language does not instruct an agent to answer in Russian.
- Exact compatibility only: use this release on `dffc2b3…`. Do not stack it over an older patch, force it onto newer source or downgrade a running instance to make it fit. Follow [the agent installation guide](../docs/AGENT-INSTALL.md), use a fresh source worktree, rebuild and separately authorize deployment.
- No running service, real credentials, production database or historical release was changed during preparation. Test the localized build in the intended deployment environment and retain normal backups.
