## Known limits

- Full server and deployment end-to-end suites were not rerun on this unchanged UI integration. Prior server failures from an earlier ru3 run are historical and are not claimed as results for ru4.
- The token gate has nine preexisting literal findings in upstream-identical `PillGuy.tsx`; new localization files did not add those findings. They were not silently fixed or declared absent.
- One upstream runtime-health source description refers to `enabled-path` while server counting includes disabled connections. The Russian text preserves the source qualification; this UI-only release does not change server behavior.
- No production service, real credentials, provider delivery or deployed database was used. Test your own isolated build and backup/upgrade procedure before deployment.
- User content, agent output, CLI, external plugins and unknown raw provider diagnostics keep their original language. Neither complete visual coverage of all possible states nor absence of future defects is claimed.
- Compatibility is exact: stable `65ec059…` only. Do not apply over an earlier Russian patch, to arbitrary `latest`, or to master; do not downgrade a running instance to fit this patch.

The original private kits, historical ZIP files, and the previous public beta release remain unchanged. This package is a new immutable release with its own manifest and checksums.
