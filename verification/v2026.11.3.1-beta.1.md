# Beta v2026.11.3.1-beta.1 — vertical language selector

Prepared November 3, 2026 for the unchanged Paperclip master snapshot
`8ea240218dc1d3a94afea1294b377021045dd9c9`, with `community-json`.
Publication must use prerelease status and must not select Latest. This record
documents local preparation; it does not itself assert publication or deployment.

## Scope / Объём изменения

Языки в меню аккаунта расположены вертикально под заголовком «Язык». Кнопки
занимают доступную ширину, имеют минимальную высоту 44 px, названия переносятся,
а выбранный язык отмечен декоративной галочкой. Список ограничен по высоте и
прокручивается. Сохранены нативный клавиатурный фокус, названия языков,
`aria-pressed`, направление текста и поведение переключения.

The account-menu selector now places full-width language buttons beneath its
heading. Labels wrap, the selected language has a decorative check, and a
bounded vertical list can scroll. Native button focus, `type="button"`, accessible
labels, pressed state, per-language direction, autonyms and locale persistence
are preserved. No additional language is enabled.

The Paperclip base, catalog bytes, provider behavior, routes, dependencies,
lockfile, database and deployment configuration are unchanged. The complete
patch is still applied to a fresh checkout at the pinned base; do not stack it
over the previous localization patch.
