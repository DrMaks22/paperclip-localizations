Reviewed on 2026-10-19. **Unpublished candidate; no merge or publication is authorized by the weekly maintenance task.** Published Latest remains `v2026.10.13.1`. Its tag, assets and historical report are unchanged.

## Compatibility and exact change

- Official Paperclip `v2026.1012.0`, exact base `bba6a45f0d364cfd962ac59b3bdf2426a8222adb`.
- Runtime profile: `pinned-en-ru`; no community runtime migration.

- Foundation and generated patch SHA-256: `23c581778af3a540757d5245bf4580548724cb3af6d7907a0cedb2b50b2ae556`.
- Complete patch: 965 files. **Delta from the previous stable is four runtime expression replacements in two components plus eight regression cases in their two existing test files.** The large complete patch is not the size of this fix.

The previous localization incorrectly translated `DataTransfer.types`' browser protocol token `Files`. Russian drag/drop could fail admission, and mixed file/text clipboard data could take the ordinary text-paste route. `MarkdownEditor` and `NewIssueDialog` now compare the literal `Files` token, as the browser expects, independently of interface language. File bytes, filenames, user content, API values and upload/create behavior are not translated or redesigned.

English and Russian catalogs are byte-identical to `v2026.10.13.1`: 19,302 and 19,682 strings respectively. There are no new translation strings requiring fluency or bilingual retranslation. Historical language-review evidence remains in the [previous report](v2026.10.13.1.md); it is not represented as a new human review. This maintenance change was implemented and reviewed by agents.

Installer source, runtime overlays, dependencies, lockfile, server, database and deployment configuration are unchanged. No live instance or upstream PR branch was modified.

## Кратко по-русски

Ошибка была в переводе служебного браузерного значения `Files`; теперь оно не зависит от языка. Каталоги перевода, зависимости и сервер не менялись.
