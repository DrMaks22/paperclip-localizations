# Stable candidate v2026.11.23.1 for Paperclip v2026.1117.0

This candidate targets official Paperclip `v2026.1117.0` at `c0f132898d2a2677312d8c72096187b27a3d9a38`. The previous published stable package is `v2026.11.9.1` for `v2026.1106.0`. Preparation of this candidate does not publish a release or deploy an instance.

## Integration

The previous stable foundation was reconstructed on its official base with public localization ancestor `9cf846bbf6f174d0d394c4faf08c18d77f54bd38`. Commit `86d9129f160d15223d29862cbcc8741bbd742102` merged reconstruction `4e4e64f2c994efbbf2e05bbbd557402aa8d2d8e2` with the official release. Russian editorial corrections followed in `1e04c68174a80b0ec9ce28af1a9bf5a3f95f045f`. The final tree is `0c26b98a6faa66505f3a8f2c2733d689592981c7`. The foundation and installer patch both have SHA-256 `06877bee72cfccf2b9ff842ca8b45900106a2befd9b74f9054f37c17b67b40e2`.

The package uses the stable `pinned-en-ru` runtime. The source patch covers 1,169 paths in the UI and existing locale-maintenance scripts. It includes new and updated text for task and chat activity, onboarding, agent and environment configuration, organization settings, external services, built-in skills and accessible controls. Exact comparisons gate the translation of known server events, queue messages, configuration warnings and bundled metadata. External diagnostics, custom descriptions and stored records retain their original values.

The English catalog gains 1,309 entries and updates the description of the built-in board skill. Catalog totals are 23,516 English and 23,954 Russian entries. The pinned catalogs use separate Russian plural forms. Reviewed translations from the previous beta were reused where the stable English copy and meaning agreed.

## Application checks

Separate agents reviewed the Russian wording without the English source and then checked the bilingual changes against their use in Paperclip. Corrections cover responsibility for actions, permission descriptions, configuration history and the outcomes of background jobs. The review covered English and Russian.

The UI TypeScript check, design-token check and production build passed. Component tests exercised English and Russian across language changes, preserving drafts, active selections, file uploads, code wrapping, run details and user-supplied text. Isolated Chromium tests switched the language six times at 390 and 1280 CSS pixels, checked the vertical language options and verified persistence after reload.

## Package and browser verification

All 119 package tests passed. The optional community-runtime test used ten individually hash-verified source files, including the reviewed vertical language selector. The shipped stable runtime uses the pinned English and Russian catalogs. The installer safety suite passed all 57 tests.

The task thread suite runs its native-runtime scenario only in the native parameterization. Vitest counts the legacy parameterization of that case as skipped. The pull request records the final suite totals. Browser coverage uses the installed UI and synthetic data. Production services and assistive technology were outside the scope of that run.

Chromium loaded components from the installed patch in a 215-pixel panel on 390- and 1280-pixel viewports. Keyboard language changes preserved a draft, updated quota details and the accessible label for a task waiting on 21 subtasks, and survived reload. All data in these scenarios was synthetic.
