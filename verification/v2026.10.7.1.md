## Explicit limitations and failed environment checks

- Full workspace `pnpm -r typecheck` was attempted and stopped in the Rust runner: this Mac has not accepted the Xcode/Apple SDK license. The host's license state was not changed. This is **not** reported as a passing workspace check.
- `pnpm check:tokens` fails because upstream's case-insensitive substring scanner treats the local username as forbidden. The clean upstream source already has 785 matching lines; identifiers such as `userLabelMap` and `initialMarkdownRenders` also match. Additional patch matches were inspected as code identifiers/catalog keys. The scanner was not weakened or bypassed; its failure is recorded separately from the passing UI design-token gates.
- Full workspace build/test, native runner compilation, Storybook visuals, real provider authentication and live-backend E2E were not completed in this pass. They are not prerequisites for applying this UI-only source patch, but remain relevant to an operator's deployment validation.
- Vite chunk-size/static-plus-dynamic-import warnings and jsdom's unsupported scroll/navigation/canvas notices remain nonfatal. No unrelated runtime behavior was changed to suppress them.
- UI coverage is for the reviewed source and runtime paths, not a guarantee of a defect-free or universally translated application. User content, agent output, unknown provider diagnostics and technical identifiers intentionally remain unchanged. No third language is certified.
