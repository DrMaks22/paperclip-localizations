## Scope and provenance

Historical note added 2026-09-13: this release is a master **beta**, despite its original unsuffixed tag. Its GitHub prerelease metadata was corrected; its tag and downloaded files remain immutable. The replacement is `v2026.9.13.1-beta.1`.

This release targets Paperclip commit `04e364236bd2f9787e4a5c581751e0b8c6c16383`, the upstream master snapshot selected and verified on 2026-09-12 UTC. The inherited localization is public commit `9cf846bbf6f174d0d394c4faf08c18d77f54bd38`; the complete reviewed integration is distributed in `patches/foundation.patch`. See the original tag's [source-lock.json](https://github.com/DrMaks22/paperclip-localizations/blob/v2026.9.12.1/source-lock.json) for exact hashes and [manifest.json](https://github.com/DrMaks22/paperclip-localizations/blob/v2026.9.12.1/manifest.json) for the generated patch boundary.

The patch changes 786 paths: 783 under `ui/` and exactly `scripts/locale-changes.mjs`, `scripts/locale-changes.d.mts`, and `scripts/sync-locales.mjs`. It changes no server implementation, database schema, package manifests, or dependency lockfiles. The source checkout itself includes the pinned upstream Photon implementation and dependency updates; those are not supplied as localization changes.

The enabled English catalog contains 16,391 messages and Russian contains 16,723, including language-specific plural forms. These are message counts, not percentages of visual or dynamic-screen coverage. Existing upstream scaffold files are not enabled as reviewed languages.

## Remaining limits

- This release does not certify live Photon enrollment, billing, message delivery, group membership, or credentials. Those provider operations were not performed.
- The complete backend and deployment end-to-end suites were not rerun for this independent distribution. Earlier upstream PR results are historical evidence, not new release checks.
- Visual checks cover the changed selector/Photon surface, not every screen, browser, viewport, or third-party application. A 320 px content-column check is not a separate mobile-device certification.
- RTL behavior was functionally exercised with a synthetic catalog; no completed third language or RTL visual certification is included.
- User content, agent output, raw provider errors and logs are not automatically translated. Future upstream changes require a new reviewed compatibility update.
- Nothing in this release was installed into or deployed over the maintainer's production instance.
